## Описание программы (кратко)

Программа Random Quote Generator — это десктопное приложение на Python с графическим интерфейсом (GUI), которое генерирует случайные цитаты из встроенной базы данных. Пользователь может добавлять собственные цитаты, просматривать историю сгенерированных цитат и фильтровать их по автору или теме.

### Возможности (что программа умеет делать)

* Генерировать случайную цитату из встроенной базы.
* Отображать цитату с указанием автора и темы.
* Добавлять пользовательские цитаты в базу данных (с проверкой на пустые поля).
* Сохранять историю сгенерированных цитат в файл `history.json`.
* Загружать историю при запуске программы (если файл существует).
* Отображать историю цитат в виде списка (новые сверху).
* Фильтровать историю по автору или теме с «живым» поиском (при вводе текста в поле фильтра).

## Инструкция по запуску

### Требования для запуска программы

* Python версии 3.6 или выше.
* Установленные библиотеки:
    * `tkinter` (обычно входит в стандартную поставку Python);
    * стандартные библиотеки `random`, `json`, `os` (не требуют отдельной установки).

### Запуск (инструкция по запуску)

1. Убедитесь, что у вас установлен Python 3.6+.
2. Сохраните код программы в файл с именем `quote_app.py`.
3. Откройте терминал или командную строку.
4. Перейдите в директорию, где сохранён файл `quote_app.py`, с помощью команды `cd`:
